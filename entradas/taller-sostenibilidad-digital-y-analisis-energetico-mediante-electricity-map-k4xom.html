Taller: Sostenibilidad digital y análisis energético mediante Electricity Map

Talleres 17/11/2026 CG cq22003 y gb23003
Lugar: Auditorio 1, 1:00 p. m. - 4:00 p. m. Expositor: Br. Josué González Herramientas: Plataforma web Electricity Maps (visualización global de intensidad de carbono y mezcla eléctrica en tiempo real) y Electricity Lab (entorno web creado por el expositor para consumir la API de Electricity Maps mediante API Keys, con secciones de Playground, tutoriales y casos prácticos). Procedimiento: La sesión se desarrolló con un formato expositivo-demostrativo. Primero, se exploró la interfaz de Electricity Maps para entender cómo se miden y visualizan indicadores clave como la intensidad de carbono la mezcla eléctrica, el porcentaje de energía renovable y el potencial eólico en distintas regiones del mundo (incluyendo ejemplos aplicados a El Salvador). Posteriormente, se presentó la arquitectura de la plataforma Electricity Lab, explicando cómo realizar peticiones GET a los endpoints de la API para obtener respuestas en formato JSON y automatizar cálculos de emisiones. Práctica: Se revisó la estructura de la sección Práctica Green IoT dentro de Electricity Lab diseñada para resolver casos de estimación de emisiones de equipos eléctricos en 35 minutos y el funcionamiento del Playground API. Aunque la demostración se centró en recorrer la herramienta y explicar cómo consumir los datos de forma teórica-visual sin ejecutar un ejercicio guiado paso a paso en vivo, quedó habilitado el entorno para realizar consultas y pruebas por cuenta propia. Resultados: Comprensión del flujo de extracción y análisis de datos energéticos en tiempo real mediante APIs abiertas, identificando cómo consultar la huella de carbono de la red eléctrica de El Salvador y otros países para fundamentar proyectos de Green IoT y sostenibilidad digital.

Nuestra reflexión

Este taller me permitió aterrizar el concepto de sostenibilidad digital desde una perspectiva técnica y medible. Muchas veces asumimos que el impacto ambiental de la tecnología es intangible, pero herramientas como Electricity Maps y su API demuestran que cada kilovatio hora consumido por nuestros sistemas tiene una huella de carbono concreta que varía según la hora y la matriz energética del país. Contar con plataformas como Electricity Lab facilita enormemente que como estudiantes de informática podamos integrar conciencia ecológica en nuestros desarrollos, por ejemplo, programando tareas pesadas o procesos IoT en horarios de menor intensidad de carbono, demostrando que la eficiencia energética también se construye desde el código y el análisis de datos
