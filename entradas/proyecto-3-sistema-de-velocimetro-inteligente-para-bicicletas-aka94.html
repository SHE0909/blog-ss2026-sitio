Proyecto #3 Sistema de velocímetro inteligente para bicicletas

Feria de proyectos 19/11/2026 CG cq22003 y gb23003
Nombre del proyecto: sistema de velocimetro inteligente para bicicleta Estudiante: Manuel Alejandro Solano Guzman Tecnologías e innovación: Este proyecto, clasificado en la categoría libre, consiste en un prototipo físico instalado directamente sobre una bicicleta. Tecnológicamente, el circuito integra un sensor "Hall magnético KY-003", un sensor "Hall lineal KY-024", un sensor de "Mercurio KY-017" y "2 imanes", los cuales están cableados a una unidad de control montada en el manubrio. Para procesar los datos de estos sensores y darle la lógica al proyecto, se utilizó el entorno de desarrollo Arduino IDE. La innovación principal de este sistema es su capacidad de monitoreo integral, ya que no solo mide velocidad, sino que también registra la cadencia de pedaleo y detecta caídas, aportando una función de seguridad para el usuario.
